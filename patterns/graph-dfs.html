Graph — DFS

Count islands or components, flood fill, reachability, bipartite.

Stage 8 · Graphs10 problems1 Easy · 8 Medium · 1 Hard

Use it when

Count islands or components, flood fill, reachability, bipartite.

Key idea

Visit a node, mark it, recurse to unvisited neighbours. Each fresh start is a new component.

How to practise this pattern

  1. Read the problem and look for the signal above before writing any code.
  2. Say the brute force out loud, with its time complexity, then ask what work it repeats.
  3. Apply the key idea and write the optimised version yourself.
  4. If you're stuck for more than 10 minutes, take one small hint, not the full solution.
  5. Move to the next problem only when you can explain why this pattern fits.
